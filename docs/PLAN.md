Architecture note (owner agreed 25 Oct 2026): features as modules. A `features` list in the world file (`music`, `lessons`, `band`, `voices`; later `weapons`, `flight`, `morphing`, `claims`) gates the server handlers (`LocationRoom` message handlers and the sims that go with them) and lazy-loads the client modules (chord bar, lesson panel, band, instruments audio) with `import()` behind the flag, so a world without music ships none of its UI and a new feature is one folder under `client/src/features/<name>` and `server/src/features/<name>` with a manifest (messages it handles, state it adds, world-file fields it reads). Done when the next feature of that size arrives, with its concrete requirements; about a day of refactoring.
